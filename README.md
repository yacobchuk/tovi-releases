# Tovi — installers

Tovi is a program for Windows and macOS that runs your YouTube and TikTok channels with your own AI agent.

**Download it from [tovi.work](https://tovi.work).** This repository holds only the installers of each version,
under [Releases](https://github.com/yacobchuk/tovi-releases/releases). The source code of Tovi is not here.

Questions: support@tovi.work
